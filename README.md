## Featured project

**[Poaching in Tanzania: When and Where Do Incidents Cluster?](https://github.com/hastur888/data-science-project)**

An analysis of 268 reported poaching incidents in Tanzania (2005-2015), examining how incidents
are distributed across years, months and regions. Status: **completed**.

uses `index.md` in the repository root as the website entry file.
